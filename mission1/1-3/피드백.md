# 민수 님께 드리는 영화 티어리스트 피드백

## 잘된 점

영화 카드를 다른 등급으로 옮기면 기존 칸에서는 사라지고 이동한 칸에만 남았고, 새 영화를 추가하면 미분류 영역에 카드가 정상적으로 생성되었습니다. 처음으로 버튼을 누르면 기본 영화 8개가 미분류로 돌아왔으며, 별도의 로그인이나 외부 파일 없이 HTML 하나로 실행할 수 있었습니다.

등급마다 색상이 달라 구분하기 편했고, 상단의 분류 진행 숫자와 드래그할 때 나타나는 칸 강조 효과도 영화를 정리하는 데 도움이 되었습니다.

## 고치면 좋을 점

### 1. 영화 목록과 등급 변경 상태 저장

- **본 것:** 영화를 추가하고 등급을 변경한 뒤 HTML을 닫았다가 다시 열었더니 추가한 영화와 변경한 등급이 유지되지 않았습니다.
- **기준:** 기획서의 '같은 브라우저에서 파일을 다시 열어도 영화와 등급이 유지된다'는 완성 기준에 맞지 않습니다.
- **제안:** 영화 목록과 각 영화의 등급을 브라우저에 저장하고, HTML을 다시 열었을 때 이전 상태가 복원되도록 개선하면 좋겠습니다.

### 2. 빈 제목 영화 추가 방지

- **본 것:** 제목을 비운 채 추가하는 상황을 확인했으며, 빈 제목 카드가 생성된다는 지적에 재검증 결과 '일치'로 표시했습니다. 다만 당시 생성된 화면에 대한 상세 메모는 남기지 못했습니다.
- **기준:** 기획서의 '제목을 입력하고 추가하면 새 영화 카드가 생성된다'는 동작에 비추어, 제목이 없는 카드는 영화 목록을 구분하기 어렵게 만듭니다.
- **제안:** 공백을 제외한 제목이 없을 때는 카드를 추가하지 않고 제목 입력을 안내하면 좋겠습니다.

### 3. 좁은 화면에서 오른쪽 잘림 해결

- **본 것:** 브라우저 창의 가로 폭을 좁혔더니 페이지 오른쪽 일부가 화면 밖으로 잘렸습니다.
- **기준:** 기획서의 '화면 폭이 좁아져도 오른쪽이 잘리지 않는다'는 완성 기준에 맞지 않습니다.
- **제안:** 화면 폭에 따라 등급 영역과 카드 배치가 조정되도록 해 좁은 화면에서도 모든 내용을 볼 수 있게 개선하면 좋겠습니다.

### 4. 먼 거리의 카드 이동 편의성 개선

- **본 것:** 미분류 영역에서 맨 위 S등급까지 카드를 드래그하는 과정이 불편하다는 의견에 직접 사용 후 동의했습니다.
- **기준:** 기획서에 명시된 드래그 이동과 '카드 선택 후 등급 클릭' 기능을 사용하면서 느낀 불편함입니다.
- **제안:** 기존의 카드 선택 후 등급 클릭 방식을 더 쉽게 발견할 수 있도록 짧은 사용 안내를 추가하거나 선택 상태를 명확히 표시하면 좋겠습니다. 이렇게 하면 긴 거리 드래그 없이도 등급을 지정할 수 있습니다.
