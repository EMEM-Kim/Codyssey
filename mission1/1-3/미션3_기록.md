## STEP 2. 받은 피드백 재검증

> 직접 해 본 결과는 STEP 2에서 기록했으며, 반영 여부와 이유는 STEP 3에서 확정했다. 일치/불일치는 당시 재검증 응답으로, 실제 관찰과 다른 경우 이를 구분했다.

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| AI A1. 저장 기능이 없어 다시 열면 배치가 초기화됨 | **일치.** STEP 1에서 영화 추가·등급 변경 후 파일을 다시 열면 상태가 유지되지 않음을 확인함 | 반영 | 같은 브라우저에서 파일을 다시 열어도 영화와 등급이 남아야 한다는 완성 기준과 다름. 저장·복원 기능 개선이 필요함. |
| AI A2. 처음으로 버튼을 눌러도 직접 추가한 영화가 남음 | **AI 지적과 불일치하는 관찰.** 새 영화를 추가한 후 처음으로 버튼을 누르자 추가한 영화가 사라짐. 재검증 선택은 '일치'였으나 실제 관찰 결과는 AI 주장과 반대임 | 보류 | 실제 확인에서는 추가한 영화가 사라졌으며, 처음 영화 목록과 배치로 돌아가야 한다는 기획서 조건에 부합함. AI 지적과 관찰이 다름. |
| AI A3. 빈 제목으로 추가하면 빈 카드가 생성됨 | **일치로 선택함.** 구체적인 관찰 메모는 없음 | 반영 | 빈 제목으로 추가되는 현상에 일치로 응답함. 제목을 입력하고 추가한다는 기획서 동작에 맞춰 빈 제목을 막는 것이 적절함. 구체적인 생성 결과는 메모가 없어 추후 기록 보완 가능. |
| 동료 P1. 등급별 색상이 달라 구분하기 좋음 | **일치로 선택함.** 별도 메모 없음 | 보류 | 등급별 색상 구분이 유용하다는 긍정 의견으로, 현재 기능을 유지하면 됨. 별도 수정 요구가 아님. |
| 동료 P2. 상단 분류 진행 숫자가 유용함 | **일치로 선택함.** 별도 메모 없음 | 보류 | 분류 진행 숫자가 유용하다는 긍정 의견이며, 현 기능을 유지하면 됨. |
| 동료 P3. 드래그 시 칸 색이 바뀌어 놓을 위치를 알기 좋음 | **일치로 선택함.** 별도 메모 없음 | 보류 | 드래그 중 칸 강조가 유용하다는 긍정 의견이며, 현 기능을 유지하면 됨. |
| 동료 D1. 휴대폰에서 사용하기 불편함 | **불일치로 선택했으나**, 브라우저 폭을 줄이면 오른쪽 화면이 잘리는 현상을 관찰함. 사용성 문제의 근거가 있으므로 선택 결과와 관찰 내용을 구분해 기록함 | 반영 | 좁은 화면에서 오른쪽이 잘리는 현상을 직접 관찰했으며, 기획서의 좁은 화면 완성 기준을 위반함. 불일치 선택보다 실제 관찰을 우선하여 판단함. |
| 동료 D2. 카드 이동 방법이 처음에는 헷갈림 | **불일치로 선택함.** 별도 메모 없음 | 보류 | 재검증에서 불일치로 판단했고 구체적인 어려움은 확인되지 않음. 기획서에 카드 선택 후 등급 클릭 또는 드래그 이동 방식이 정해져 있음. |
| 동료 D3. 미분류에서 S등급까지 드래그하기 불편함 | **일치로 선택함.** 별도 메모 없음 | 반영 | 긴 거리 드래그가 불편하다는 의견에 일치로 응답함. 기획서의 카드 선택 후 등급 클릭 기능을 더 쉽게 알아보게 하는 방향으로 사용성을 개선할 수 있음. |
| 동료 D4. 카드 색이 칙칙함 | **일치로 선택함.** 별도 메모 없음 | 보류 | 칙칙하다는 평가는 주관적 취향이며, 가독성 저하나 기획서 위반이 확인된 것은 아님. |
| 동료 D5. 영화 포스터가 있으면 좋겠음 | **일치로 선택함.** 별도 메모 없음 | 보류 | 포스터 추가는 취향에 따른 제안이고 기획서 필수 조건이 아님. 단일 HTML 파일 조건도 고려해야 함. |
| 동료 D6. C등급은 없어도 될 것 같음 | **불일치로 선택함.** 별도 메모 없음 | 보류 | S·A·B·C 네 등급은 기획서에 명시되어 있어 C등급을 없애면 기획서 조건과 충돌함. |

- **아무도 말하지 않았는데 내가 찾은 것:** 브라우저 화면 폭을 좁히면 오른쪽이 잘리는 현상. AI 검토에서는 언급되지 않았으며, 동료의 '휴대폰에서 불편함'과 관련되지만 보다 구체적인 관찰임.
- **(선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유:** AI A2는 실제 관찰과 반대였는데도 '일치'로 체크된 이유를 비교하고, D1처럼 평가 선택과 관찰 결과가 다른 경우 어떤 근거로 판단해야 하는지 이야기하고 싶음.
