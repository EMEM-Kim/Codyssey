# 미션 1 기록

- **AI A:** Claude — https://claude.ai/share/2f7a0795-4874-432b-9df1-ae422c488915
- **AI B:** ChatGPT — https://chatgpt.com/share/6ae98fc1-e8d0-83ee-8253-c711f92bcd74
- **비교 기준:** 최초 TMDB 기반 기획서와 두 AI 초안의 실제 HTML 소스
- **비교 파일:** `movie_tierlist_초안_claude.html`, `movie-tierlist_초안_chatgpt.html`

## AI가 물어서 내가 정한 것
- 사용자: 본 영화를 분류하려는 개인 사용자
- 목적: 6개 등급으로 정리하고 브라우저에서 저장
- 등급: 걸작 / 명작 / 대작 / 역작 / 수작 / 평작
- 화면: 6개 행과 하단 고정 검색·입력 영역
- 동작: 카드 배치·이동·삭제 및 자동 저장
- 최초 기획: TMDB 검색 결과의 포스터 카드
- 최종 변경: API 제거, 영화 제목 직접 입력·텍스트 카드

질문 원문은 위 대화 공유 링크에서 확인한다. 평가에서 요구하는 질문 원문 캡처는 별도 첨부가 필요하다.

## 같은 행동으로 비교한 결과

**이 표는 코드 분석 결과이며 실제 브라우저 테스트 통과를 의미하지 않는다.** 두 초안 모두 TMDB 인증값이 빈 문자열이므로 그대로는 실제 영화 검색이 불가능하다.

| 해본 행동 / 비교 항목 | 기대 결과 | AI A(Claude) 코드 | AI B(ChatGPT) 코드 |
|---|---|---|---|
| 초기 화면 열기 | 6개 등급과 하단 검색 영역 | 6개 등급 및 하단 검색 폼 구현 | 6개 등급, 하단 검색창과 대기 영역 구현 |
| 제목 검색 | 검색 결과 표시 | 검색 버튼 제출 시 TMDB 호출, 토큰 없으면 안내 문구 | 입력 350ms 후 자동 검색, 키 없으면 안내 문구 |
| 결과 선택 | 카드 추가 | 선택 즉시 걸작 행에 추가 | 선택 시 하단 pool에 추가 |
| 등급 배치 | 카드 이동 | 행 자체에 drop 이벤트 | 등급별 zone에 drop 이벤트 |
| 등급 간 이동 | 카드 위치 변경 | movie.tier 변경 | 기존 목록에서 제거 후 대상 목록에 추가 |
| 삭제 | 카드 제거 | 드래그 중 우측 상단 삭제 영역 표시 | 하단 휴지통 항상 표시 |
| 저장 | 새로고침 후 보존 | localStorage에 영화 배열 저장 | localStorage에 pool/rows 저장 |
| 실제 브라우저 동작 | 실행 증거 확보 | 미검증 | 미검증 |

**참조:** 위 두 HTML 파일. 브라우저 캡처는 아직 제출되지 않았으며 `테스트_체크리스트.md`에 수집 절차를 정리했다.

## 선택한 파일명과 고른 이유
- **최종 수정본:** `수정본/movie_tierlist_color_FIXED.html`
- **선택 이유:** TMDB 인증 없이 단일 HTML로 영화 제목 추가, 등급 이동, 삭제 및 저장을 구현하도록 수정했고, 색상 선택자 불일치 문제를 코드상 수정했다.
- 최초 두 초안 중 어느 쪽의 실제 브라우저 성능이 우수했는지는 검증되지 않았다. 최종본 선택은 수정 이력과 코드 구조를 근거로 한다.
