# 미션 2-3 — 테스트하며 고치고 사용자 피드백 반영하기

v4 작성자 브라우저 검증은 완료했습니다. v5 중복 등록 방지와 v6 확장 기능은 추가 브라우저 테스트가 필요합니다.

## 파일

- `캐릭터퀴즈_v2.html`: 정답 비교 로직을 수정하고 사용자 추가 테스트 3건 PASS를 확인한 버전.
- `캐릭터퀴즈_v3.html`: 정답 수정 시 갤러리 전체 재생성을 줄인 수정본. **사용자 테스트 4항목 PASS**.
- `캐릭터퀴즈_v4.html`: 친구의 결과 화면 관련 관찰을 반영하여 점수 표시 화면의 시각적 강조를 개선한 버전. **작성자 재검증 4건 PASS**.
- `캐릭터퀴즈_v5.html`: 중복 이미지 등록 방지 수정본. **브라우저 검증 대기**.
- `캐릭터퀴즈_v6.html`: 기본/타임어택(20초) 모드, 연속 정답 콤보, 게임당 3회 첫 글자 힌트, 결과 화면 오답 노트. **브라우저 검증 대기**.
- `기획서.md`: v4에 맞게 화면·기능·완료 기준을 수정한 문서.
- `제작검증기록.md`: 미션 2-2 비교/테스트 기록과 미션 2-3 수정 1 및 회귀 테스트의 사용자 확인 결과를 통합한 진행본.

## v3 테스트 완료 항목

1. 등록된 여러 이미지의 정답을 수정하면서 Tab 키로 다음 입력란으로 이동할 수 있는지
2. 정답 수정 후 새로고침하여 변경 내용이 저장되었는지
3. 빈 정답일 때 게임 시작 제한이 유지되는지
4. 이미지 등록·삭제와 퀴즈 정답 판정이 기존대로 작동하는지

친구 1명이 결과 화면이 심심하다는 관찰을 전달함(별도 명시적 피드백은 없음). 이를 바탕으로 v4를 제작했고 결과 화면·최종 점수·재시작·기존 기능을 작성자가 테스트하여 모두 PASS로 보고했습니다.

**최종 제출 후보 HTML:** `캐릭터퀴즈_v6.html` 1개(브라우저 테스트 완료 후 확정). v2/v3/v4/v5는 버전별 수정 증빙으로 보존.

**제출 전 확인:** 친구의 명시적 개선 의견, 실제 공통 프롬프트 원문, 필요한 화면 캡처·증빙 확인.

**주의:** 기존 미션 2-2 파일은 수정하지 않습니다. 기존 브라우저의 localStorage 저장 데이터가 재사용될 수 있습니다.


## v5 테스트 항목 (미실시)

1. 이미 등록한 동일 이미지 파일을 다시 선택해도 등록 이미지 수가 늘지 않음
2. 같은 선택에 중복 파일이 있으면 한 번만 등록됨
3. 중복 제외 개수 안내 표시
4. 서로 다른 새 이미지는 정상 등록됨
5. 새로고침 후 동일 파일 재등록 차단
6. 퀴즈 정답 판정·결과 점수·재시작 정상 동작


## v6 설계 및 테스트 포인트

- 기본 모드: 기존 방식 그대로 진행, 시간 제한 없음
- 타임어택: 문제마다 20초 제한, 시간 초과 시 오답 처리 후 다음 문제로 이동
- 콤보: 정답 시 증가, 오답/건너뛰기/시간 초과 시 0으로 초기화(점수에는 미가산)
- 힌트: 게임당 3회, 문제당 1회, 정답 첫 글자 노출
- 오답 노트: 결과 화면에 틀린 문제 이미지·정답·사용자 입력/건너뛰기/시간 초과 사유 표시
- 직접 테스트 권장: 콤보/힌트 제한/시간 초과/오답 노트/재시작/중복 이미지 등록/기존 기능 정상 작동

**상태:** 구현 후보 업로드 완료, 브라우저 실제 테스트는 아직 실시하지 않음.
