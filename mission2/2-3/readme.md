# 미션 2-3 — 테스트하며 고치고 사용자 피드백 반영하기

현재까지 확인한 내용을 저장한 **진행 중 작업 폴더**입니다. 최종 제출 완료 상태가 아닙니다.

## 파일

- `캐릭터퀴즈_v2.html`: 정답 비교 로직을 수정한 테스트 버전. HTML 하나에 CSS/JS 포함.
- `기획서.md`: 미션 2-1 기획서를 바탕으로 한 진행본. 최종 수정 이후 갱신 필요.
- `제작검증기록.md`: 미션 2-2 비교/테스트 기록과 미션 2-3 수정 1 및 회귀 테스트의 사용자 확인 결과를 통합한 진행본.

## 테스트할 항목

1. 공백·영문 대소문자를 다르게 입력했을 때 정답 처리 여부
2. 빈 답안 제출 시 결과와 다음 문제 동작
3. 이미지 9장으로 게임 시작 제한 여부

이후 발견된 실제 문제를 하나씩 수정해 v3 등을 만들고, 사용자 1명 피드백을 반영할 예정입니다.

**주의:** 기존 미션 2-2 파일은 수정하지 않습니다. 기존 브라우저의 localStorage 저장 데이터가 재사용될 수 있습니다.
