# 캐릭터 이미지 맞추기 퀴즈 사이트 기획서

> 미션 2-3 v6 확장 기능을 반영한 기획서. v4까지 사용자 검증 완료, v5 중복 등록 방지 및 v6 확장 기능은 브라우저 추가 테스트 필요.

## 1. 대상 사용자

- 친구들과 함께 애니메이션·게임 등 다양한 캐릭터의 이름을 맞히며 즐기려는 사람.
- 한 사람이 문제에 사용할 이미지를 준비하고, 같은 기기에서 친구들과 번갈아 답을 입력하며 게임을 즐기는 사용자.

## 2. 사용 목적

- 사용자가 준비한 캐릭터 이미지로 별도의 계정이나 서버 없이 퀴즈를 구성한다.
- 파일명을 정답으로 자동 등록해 문제 준비에 드는 수고를 줄이고, 등록된 모든 캐릭터를 무작위 순서로 한 번씩 맞힌다.
- 게임 종료 시 맞힌 문제 수를 확인하고 같은 이미지로 다시 도전한다.

## 3. 화면 구성과 동작

### 3-1. 이미지 등록·관리 화면

- 하나의 HTML 파일에서 **이미지 등록 → 퀴즈 진행 → 결과 확인** 순서로 화면 영역을 전환한다. 별도 페이지 이동은 없다.
- 이미지 파일 여러 장을 한 번에 선택해 등록한다. 지원 형식은 JPG/JPEG, PNG, WebP로 한정한다. 이미 등록된 파일과 내용(Base64 데이터 URL)이 동일한 이미지는 다시 등록하지 않으며, 한 번에 선택한 파일 안의 중복도 제외한다. 제외한 중복 개수를 화면에 안내한다.
- 파일명에서 마지막 확장자를 제외한 문자열을 기본 정답으로 자동 입력한다. 예: `고죠 사토루.png` → `고죠 사토루`.
- 각 이미지의 미리보기와 정답 입력란을 표시한다. 사용자는 게임 시작 전에 정답을 수정할 수 있다. 정답 수정 시 전체 카드 목록을 다시 생성하지 않고 안내 문구 및 시작 가능 상태만 갱신한다. 정답이 빈 항목은 게임 시작 조건을 충족하지 못한다.
- 각 이미지의 **개별 삭제**와 등록 이미지 **전체 삭제**를 제공한다. 전체 삭제는 확인 절차를 거친 후 수행한다.
- **정상 등록되어 저장된 이미지가 10장 이상이고 모든 정답이 비어 있지 않을 때** 게임을 시작할 수 있다. 등록 화면에서 기본 모드 또는 타임어택 모드를 선택한다. 등록 수와 안내 문구를 표시한다.
- 이미지 원본을 브라우저에서 Base64 데이터 URL로 변환해 정답과 함께 localStorage에 저장한다. 페이지를 새로고침하면 저장된 목록을 복원한다. 정답 수정·삭제도 저장 내용에 반영한다.
- 저장 공간 부족 등으로 등록·수정·삭제 결과를 저장하지 못하면 오류를 안내하고 해당 변경을 확정하지 않는다. 저장에 실패한 신규 이미지는 등록 개수에 포함하지 않는다.

### 3-2. 퀴즈 진행 화면

- 게임을 시작할 때 등록된 이미지 목록을 무작위로 섞고, **각 이미지를 정확히 한 번씩** 출제한다.
- 캐릭터 이미지, 현재 문제 번호/전체 문제 수(예: `3 / 12`), 정답 입력란, `제출`, `건너뛰기` 버튼을 표시한다.
- 답안을 제출하면 정답 여부와 실제 정답을 즉시 표시한다. 정답 판정 시 입력값과 저장된 정답 모두에서 유니코드 NFKC 정규화를 적용한 후 공백 및 일부 비가시 문자를 제거하고 영문 대소문자를 구분하지 않는다. 부분 일치는 인정하지 않는다.
- 답안을 제출한 뒤에는 같은 문제의 답을 다시 제출할 수 없다. `다음 문제` 버튼을 눌러 이동한다.
- `건너뛰기`는 해당 문제를 오답으로 처리하고 실제 정답을 공개한다. 이후 `다음 문제` 버튼으로 이동한다.
- **연속 정답 콤보:** 정답 시 콤보가 1씩 증가하고, 오답·건너뛰기·시간 초과 시 0으로 초기화된다. 콤보는 참고 정보이며 기존 정답 수 점수에 가산하지 않는다.
- **힌트:** 게임당 총 3회까지 정답 첫 글자를 공개할 수 있다. 한 문제당 1회만 가능하며, 힌트 사용 자체는 정답 수에 영향을 주지 않는다. 새 게임을 시작하면 힌트 횟수가 초기화된다.
- **타임어택 모드:** 선택 시 각 문제마다 20초 제한이 적용된다. 제한 시간이 지나면 자동으로 오답 처리하고 실제 정답을 공개한다. 정답을 제출하거나 건너뛰면 타이머가 정지하고 다음 문제에서 새로 시작한다. 기본 모드는 시간 제한이 없다.
- 마지막 문제까지 처리하면 결과 화면으로 전환한다.

### 3-3. 결과 화면

- 최종 **정답 수/전체 문제 수**만 표시한다(예: `8 / 10`). 친구의 결과 화면에 대한 관찰을 바탕으로 트로피 아이콘, 그라데이션 배경, 강조된 큰 점수 글씨를 배치하여 시각적 완성도를 높인다. 정답률이나 순위표 및 추가 수치 정보는 표시하지 않는다.
- `다시 시작` 버튼을 누르면 등록 이미지와 정답을 유지한 채 점수와 진행 상태를 초기화하고 문제 순서를 다시 섞어 새 게임을 시작한다.
- 결과 화면에는 오답 노트를 표시하며, 오답·건너뛰기·시간 초과 문제의 이미지, 실제 정답, 입력 내용(또는 사유)을 확인할 수 있다. 모두 맞힌 경우 오답 노트 목록은 표시하지 않는다.
- 이미지 목록을 관리하려면 등록·관리 화면으로 돌아갈 수 있으며, 돌아가더라도 등록 데이터는 삭제되지 않는다.

## 4. 필요한 자료

- 사용자가 직접 준비한 캐릭터 이미지 **10장 이상**과 각 이미지의 캐릭터 이름.
- 이미지 파일명은 정답의 초깃값으로 활용한다. 파일명이 실제 캐릭터 이름과 다르면 사용자가 등록 화면에서 수정한다.
- 이미지는 사용자 기기에서 선택하며 외부 이미지 URL, 외부 글꼴, 라이브러리, API, 서버는 필요하지 않다. HTML 파일에 CSS와 JavaScript를 함께 포함한다.
- 이미지의 저작권과 사용 권한은 이미지를 준비하는 사용자가 확인한다. 본인이 제작했거나 이용 권한이 있는 이미지를 사용하며, 별도 제공·배포용 이미지 자료는 포함하지 않는다.

## 5. 필수 기능

1. 여러 이미지 일괄 등록, 동일 파일 내용의 중복 등록 방지 및 제외 개수 안내, 파일명 기반 정답 자동 추출, 정답 수정 및 이미지 미리보기.
2. 개별 삭제·전체 삭제 및 localStorage 저장·새로고침 후 복원.
3. 최소 10장 및 정답 입력 여부 검사, 저장 실패 시 오류 안내.
4. 전체 이미지 무작위 중복 없는 출제 및 현재 문제 번호 표시.
5. 주관식 답안 제출, 공백·영문 대소문자 무시 판정, 정답 즉시 공개.
6. 문제 건너뛰기(오답 처리), 다음 문제 이동.
7. 트로피와 시각적 강조를 포함한 결과 화면에서 최종 정답 수 표시, 기존 이미지를 유지한 게임 재시작.
8. 연속 정답 콤보·힌트(첫 글자, 게임당 3회)·오답 노트·문제당 20초 타임어택을 제공한다. 기본 모드는 기존 점수·출제 규칙을 유지한다.
9. 단일 HTML 파일을 브라우저에서 열어 별도 로그인·서버·API 없이 동작.

## 6. 추가 기능 (이번 구현 범위에서 제외, 향후 고려)

- 오답만 모아 다시 풀기.
- 힌트 유형 추가(글자 수 힌트, 이미지 일부 공개 등).
- 이미지·정답 묶음 내보내기 및 가져오기.

## 7. 한계 및 비목표 (3가지)

1. **로그인 및 온라인 계정 기능 제외:** 사용자별 계정이나 클라우드 동기화를 제공하지 않는다. 원본 이미지를 localStorage에 저장하므로 브라우저 저장 용량 제한이 있으며, 용량 초과 또는 브라우저 데이터 삭제 시 보존을 보장하지 않는다.
2. **온라인 멀티플레이 및 실시간 대결 제외:** 같은 기기에서 함께 즐기는 용도이며, 다른 기기와 실시간으로 점수나 문제를 동기화하지 않는다.
3. **AI 이미지 인식 및 자동 캐릭터 판별 제외:** 이미지 내용으로 이름을 추측하지 않는다. 파일명에서 가져온 정답을 사용자가 확인·수정해야 한다.

## 8. 검증 방법 (1가지)

**정답 판정 및 점수 대조 테스트**

- **비교 대상:** 테스트 진행자가 종이에 기록한 정답 7개·오답 2개·건너뛰기 1개(총 10문제)와 웹페이지 최종 결과의 정답 수.
- **절차:** 서로 다른 캐릭터 이미지 10장을 등록하고 정답을 확인한 뒤 게임을 시작한다. 무작위 출제 순서와 관계없이 실제 표시된 정답을 기준으로 7문제에는 정확한 이름(일부는 공백을 빼거나 영문 대소문자를 바꿔 입력), 2문제에는 명백히 틀린 이름을 입력하고, 1문제는 건너뛴다. 매 문제에서 판정과 공개된 정답을 확인하고 수기로 정답 개수를 기록한다.
- **합격 조건:** 정답으로 의도한 7문제만 정답 처리되고, 오답 2문제와 건너뛰기 1문제는 정답 수에 포함되지 않아 최종 결과가 `7 / 10`으로 표시된다.

## 9. AI 활용 및 기획 검토

- **사용한 AI 서비스:** OpenAI ChatGPT
- **사용한 모델:** GPT-6
- **활용 방식:** AI가 단계별로 제시한 질문에 답하며 대상 사용자, 화면 구성, 필수·추가 기능, 비목표, 검증 방법과 완료 기준을 구체화했다. 최종 구현 범위는 사용자 답변을 우선하여 정리했다.
- **모호한 표현 보완:** '랜덤 출제'는 한 게임에서 모든 등록 이미지를 중복 없이 한 번씩 출제하는 것으로, '이름 자동 등록'은 이미지 인식이 아닌 확장자를 제외한 파일명 사용으로 정의했다. '정답 인정'은 공백 제거·영문 대소문자 무시 후 전체 문자열 일치로 정의했다. '이미지 유지'는 같은 브라우저의 localStorage에서 복원하는 것으로 명시했다.

## 10. 완료 기준

- JPG/JPEG, PNG, WebP 이미지 여러 장을 한 번에 선택하면 각 이미지의 미리보기와 확장자를 제외한 파일명 기반 정답이 표시된다. 동일한 내용의 이미지 파일을 다시 등록하거나 같은 선택에 중복 포함해도 하나만 등록되고 중복 제외 개수가 안내된다.
- 정답 입력란을 수정하고 새로고침하면 수정된 정답이 복원된다.
- 이미지 9장만 정상 저장했거나 정답이 빈 이미지가 있으면 게임을 시작할 수 없고, 이미지 10장 이상이 정상 저장되고 모든 정답이 입력되면 게임을 시작할 수 있다.
- 개별 삭제를 누르면 해당 이미지만 목록과 저장 데이터에서 제거된다. 전체 삭제를 확인하면 모든 이미지와 정답이 목록과 저장 데이터에서 제거된다.
- 저장 용량 초과 등으로 이미지 저장에 실패하면 오류 메시지가 표시되고 실패한 이미지는 등록 목록과 게임 문제에 포함되지 않는다.
- 10장으로 게임을 시작하면 문제 번호가 `1 / 10`부터 `10 / 10`까지 표시되고, 같은 이미지는 한 게임에서 두 번 출제되지 않는다.
- 정답이 `고죠 사토루`일 때 `고죠사토루`를 제출하면 정답으로 판정되고, `사토루`만 제출하면 오답으로 판정된다.
- 답안을 제출하거나 건너뛰기를 누르면 정답·오답 여부와 실제 정답이 표시되고, `다음 문제` 버튼을 눌러야 다음 문제로 이동한다. 건너뛰기는 정답 수를 늘리지 않는다.
- 기본 모드에서 10문제 중 정답 7개, 오답 2개, 건너뛰기 1개면 결과 화면에 `7 / 10`이 표시된다. 오답 노트에는 틀린 2문제와 건너뛴 1문제가 포함된다.
- 연속 3문제 정답 시 콤보 3, 다음 문제 오답 시 콤보 0으로 표시된다. 첫 글자 힌트는 게임당 최대 3회, 문제당 1회만 사용 가능하다.
- 타임어택에서 제한 시간 20초 경과 시 해당 문제는 오답 처리되고 정답이 공개되며, `다음 문제`로 이동한다. 제한 시간 내 제출 시 타이머가 중지된다.
- 결과 화면에서 `다시 시작`을 누르면 이미지·정답은 유지되고 점수와 문제 진행 상태가 초기화되며, 모든 이미지가 다시 무작위 순서로 출제된다.
- 같은 브라우저에서 새로고침해도 성공적으로 저장된 이미지·정답 목록이 복원되며, 사용자가 직접 삭제한 항목은 복원되지 않는다(브라우저 저장 데이터가 유지되는 경우).
- HTML 파일 하나를 브라우저에서 직접 열어 로그인, API 키, 별도 서버, 추가 로컬 파일 없이 이미지 등록부터 퀴즈 결과 확인까지 진행할 수 있다.

## 11. v7 힌트 문자 표시 보완

- 첫 글자 힌트는 분해된 한글 자모로 저장된 이름이라도 NFC 정규화 후 **완성형 첫 음절**을 공개한다. 예: `로`가 첫 글자라면 `ㄹ`이 아닌 `로`를 표시한다.
- v7 수정 부분은 기존 정답 판정 규칙, 힌트 사용 횟수, 타임어택 시간 제한 및 이미지 저장 방식에 영향을 주지 않도록 구현한다.
- **추가 검증:** 분해형 한글 이름, 일반 한글 이름, 영문 이름을 각각 등록하고 힌트 첫 글자를 확인한다.
