# 챔피언 이미지 보관 폴더

캐릭터 퀴즈 테스트를 위한 리그 오브 레전드 챔피언 이미지 ZIP 파일의 보관 위치입니다.

- 업로드 대상: `롤_챔피언_이미지_전체.zip` (사용자 제공, 174개 PNG 이미지)
- 현재 상태: **ZIP 원본 미업로드**. GitHub 연결의 바이너리 업로드 기능이 지원되지 않아 GitHub 웹에서 직접 업로드해야 합니다.
- 업로드 경로: `mission2/2-3/img/롤_챔피언_이미지_전체.zip`
- GitHub 웹의 이 폴더에서 **Add file → Upload files**를 클릭하고 ZIP을 선택한 후 **Commit changes**를 눌러 업로드합니다.
- 이미지는 라이엇 게임즈의 리그 오브 레전드 관련 자료이며, 제작자의 권리와 사용 정책을 준수해야 합니다.
