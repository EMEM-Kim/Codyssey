# 제작·검증 기록: 캐릭터 이미지 맞추기 퀴즈

## 1. 두 AI 제작 및 비교

- **AI A:** Google Gemini (세부 모델명 확인 필요)
- **AI B:** ChatGPT (GPT-6)
- **동일하게 전달한 자료:** 미션 2-1의 `기획서.md`
- **동일하게 전달한 요청:** 아래는 제작 당시 사용하기로 정한 공통 요청의 요약이다. **최종 제출 전 실제 전달한 프롬프트 원문으로 교체해야 한다.**
  - 기획서의 화면 구성·기능·완성 기준을 준수한다.
  - HTML·CSS·JavaScript를 하나의 HTML 파일에 포함한다.
  - 서버·로그인·API 키·외부 라이브러리 없이 브라우저에서 실행한다.
  - 이미지 등록·관리, 퀴즈 진행, 결과 확인을 구현하고 기획서에 없는 기능은 추가하지 않는다.
  - 모바일 화면을 고려하고 한국어 문구를 사용한다.

| 테스트 3: 조건 변경 | PASS | PASS |

### 최종 선택

- **선택 후보:** Gemini 제작 `캐릭터퀴즈_v1.html`
- **선택 근거(작성자 최종 확인 필요):** 두 결과물 모두 정확한 정답을 오답으로 처리하는 문제가 있었다. Gemini는 건너뛰기 시 오답 처리와 정답 안내가 정상 표시되었으나, ChatGPT는 Enter 입력 시 판정 안내 없이 다음 문제로 이동하는 현상도 나타났다. 따라서 관찰된 문제의 범위와 피드백 표시를 고려해 Gemini 결과물을 선택한다.
- **제출:** Gemini HTML 1개. ChatGPT HTML은 비교 자료로만 보관하고 제출하지 않는다.

## 2. 선택한 HTML 테스트 기록

테스트 대상: **Gemini 제작 `캐릭터퀴즈_v1.html`**. 실제 결과는 작성자가 브라우저에서 관찰하여 전달한 내용이다.

| 번호 | 테스트 내용 | 예상 결과 | 실제 결과 |
| --- | --- | --- | --- |
| 1 | JPG·PNG·WebP 이미지 10장을 일괄 등록하고 정답 하나를 수정한 뒤 새로고침 | 10장 모두 표시, 수정한 정답 유지, 시작 버튼 활성화 | **PASS.** 이미지 등록·정답 수정·새로고침 후 저장 상태와 시작 조건이 정상 동작함 |

## 3. 미선택 결과물 기록

- **ChatGPT (GPT-6), `v1_html.html`:** 이미지 등록·저장 및 조건 변경 테스트는 정상. 정확한 정답을 입력해도 오답으로 표시되는 문제를 관찰함. 정답 입력 후 Enter를 누르면 정답·오답 판정이 나타나지 않고 다음 문제로 넘어가는 현상도 관찰함.
- **증빙:** 비교 표와 관찰 기록으로 남김. 가능하면 두 결과물의 관리 화면, 오답 판정 화면, Enter 입력 직후 화면을 캡처해 첨부한다.
