# 🎬 영화 티어리스트 웹페이지 기획서

- 작성일: 2026-11-03
- 버전: 1.1 (최종 구현 변경 사항 반영)
- 작성자: EMEM-Kim (GitHub 계정명)

## 1. 누가 쓰나
자신이 본 영화를 등급별로 직접 분류하고 기록하려는 개인 사용자.

## 2. 무엇을 하려고
영화를 여섯 단계로 정리하고, 로그인 없이 브라우저에서 사용하며 기록을 유지한다.

## 3. 화면과 동작
- 한 페이지에 걸작 / 명작 / 대작 / 역작 / 수작 / 평작 순서로 표시한다.
- 화면 하단에 고정된 영화 제목 입력창과 대기 영역을 둔다.
- 영화 제목을 입력하고 '추가'를 누르면 텍스트 카드가 대기 영역에 생성된다.
- 카드를 드래그 앤 드롭으로 등급에 배치하거나 다른 등급 및 대기 영역으로 이동한다.
- 드래그 중 나타나는 우측 상단 삭제 영역에 놓아 카드를 삭제한다.
- 카드 클릭으로도 등급·대기·삭제를 선택할 수 있다.
- 여섯 등급은 색상으로 구분하고 카드 글자 대비를 확보한다.
- localStorage에 자동 저장한다.

## 4. 필요한 자료
외부 API 및 토큰 없이 단일 HTML 파일로 실행한다.

## 5. 완성 기준
1. 영화 제목 입력 후 대기 영역에 텍스트 카드가 생성된다.
2. 카드를 6개 등급 중 하나에 배치할 수 있다.
3. 배치된 카드를 다른 등급으로 이동할 수 있다.
4. 드래그 중 표시되는 삭제 영역에 놓아 삭제할 수 있다.
5. 새로고침 및 같은 브라우저에서 재실행 후 배치가 유지된다.
6. 입력창은 스크롤해도 하단에 고정된다.
7. 등급별 색상이 구분되고 글자를 읽을 수 있다.

## 6. 최초 기획과의 차이
최초에는 TMDB API 검색과 포스터 카드를 기획했다. API 토큰 설정 문제를 겪으며 외부 API를 제거하고 제목 직접 입력·텍스트 카드로 변경했다. 이는 최초 기획의 검색·포스터 요구사항을 구현한 것이 아니라 요구사항을 변경한 것이다.
