# 🎬 영화 티어리스트 웹페이지 기획서

---

## 1. 누가 쓰나

- 자신이 본 영화를 등급별로 직접 분류하고 기록하려는 **개인 사용자**

---

## 2. 무엇을 하려고

- 본 영화를 6단계 등급으로 나눠 **한눈에 정리**하기 위해
- 별도 로그인 없이 **브라우저에서 바로** 사용하기 위해
- 브라우저를 껐다 켜도 **기록이 유지**되도록 하기 위해

---

## 3. 화면과 동작

### 화면 구성
- 6개 등급 행이 **한 페이지에 전부** 표시됨
- 각 행의 이름은 순서대로: **걸작 / 명작 / 대작 / 역작 / 수작 / 평작**
- 영화 검색창은 **페이지 하단에 고정**

### 동작
- 검색창에 영화 제목을 입력하면 **TMDB API로 검색 결과** 표시
- 검색 결과에서 영화를 선택하면 **포스터 이미지 카드**가 생성됨
- 카드에는 **포스터 이미지만** 표시 (제목·연도 등 텍스트 없음)
- 카드를 드래그 앤 드롭으로 **원하는 등급 행에 배치** 가능
- 카드를 드래그 앤 드롭으로 **다른 등급 행으로 이동** 가능
- 카드를 드래그 앤 드롭으로 **삭제** 가능

> ⚠️ **미정 항목**: 삭제 시 드롭 위치(예: 휴지통 영역, 행 밖으로 드래그 등)는 아직 정해지지 않았어요. 개발 전에 결정이 필요합니다.

---

## 4. 필요한 자료

- **TMDB API 키** (영화 검색 및 포스터 이미지 제공)
- TMDB API 문서: https://developer.themoviedb.org/docs

---

## 5. 완성 기준

1. 브라우저에서 영화 제목을 검색하면 포스터 카드가 나타난다
2. 포스터 카드를 드래그해서 6개 등급 행 중 하나에 놓을 수 있다
3. 이미 배치된 카드를 드래그해서 다른 등급 행으로 옮길 수 있다
4. 이미 배치된 카드를 드래그해서 삭제할 수 있다
5. 브라우저를 완전히 닫았다가 다시 열어도 배치된 카드가 그대로 남아있다
6. 검색창은 스크롤을 내려도 항상 화면 하단에 고정되어 있다

---

> ⚠️ **개발 전 결정이 필요한 항목**
> - 삭제를 위한 드롭 영역을 어떻게 표시할지 (예: 휴지통 아이콘, 행 밖 영역 등)
