# 영화 티어리스트 — TMDB 토큰 로컬 설정

1. `secure.example.js`를 복사하여 `secure.js`를 만듭니다. (압축파일에는 빈 `secure.js`가 포함되어 있습니다.)
2. `secure.js`의 따옴표 안에 본인의 **TMDB API Read Access Token**을 입력합니다. 실제 토큰을 채팅이나 GitHub에 공유하지 마세요.
3. `movie_tierlist_수정본.html`을 브라우저에서 엽니다. HTML과 `secure.js`는 같은 폴더에 있어야 합니다.
4. 검색이 되지 않으면 인터넷 연결, 브라우저 개발자 도구의 콘솔, 토큰 값을 확인합니다.

`.gitignore`는 `secure.js`가 **새로 Git에 추가되는 것**을 방지합니다. 이미 커밋했다면 별도로 Git 추적과 과거 기록을 처리하고 토큰을 교체해야 합니다.

주의: 이 방식은 GitHub에 토큰을 커밋하지 않게 할 뿐, 브라우저에서 사용하는 토큰을 완전히 숨기지는 못합니다. 공개 배포에는 서버 측 프록시가 필요합니다. 또한 원래 과제의 HTML 단일 파일 조건과는 다릅니다.
