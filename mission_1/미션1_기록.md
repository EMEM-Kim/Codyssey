## AI가 물어서 내가 정한 것

- **사용자:** 자신이 본 영화를 등급별로 분류하고 기록하려는 개인 사용자
- **목적:** 영화를 여섯 단계로 나눠 한눈에 정리하고, 로그인 없이 브라우저에서 사용하며, 다시 열어도 기록을 유지하기
- **등급:** 걸작 / 명작 / 대작 / 역작 / 수작 / 평작
- **화면:** 여섯 등급 행을 한 페이지에 표시하고, 영화 입력·검색 영역을 화면 하단에 고정
- **조작:** 영화 카드를 드래그 앤 드롭으로 등급에 배치하거나 다른 등급으로 이동하고 삭제
- **저장:** 브라우저에 영화 배치 상태 저장
- **초기 기획:** TMDB API로 영화를 검색하고 포스터 카드 표시
- **이후 변경:** TMDB 토큰 설정 및 실행 문제로 외부 API를 제거하고 영화 제목을 직접 입력하는 텍스트 카드 방식으로 변경

## 검증 상태 안내

AI A와 AI B의 동작 차이는 소스 코드 분석 결과이며, 실제 브라우저 테스트 성공을 의미하지 않는다. 브라우저 실행 캡처와 테스트 결과는 별도로 수집해야 한다.
